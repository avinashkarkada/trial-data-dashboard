# trial-data-dashboard
End-to-end clinical data analysis repo with SQLite data modeling, statistical analysis, and an interactive dashboard.

## Project status
Initial repository setup in progress.

## Planned components
- `load_data.py` to initialize the SQLite database and load the CSV
- `generate_outputs.py` to generate summary tables, statistics, and plots
- `dashboard.py` to run the interactive dashboard
- `Makefile` to support setup, pipeline execution, and dashboard launch
